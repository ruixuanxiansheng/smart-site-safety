# 智筑安监 · 智慧工地安全管控平台

基于 AI 视觉的建设施工脚手架安全隐患识别与管控系统，面向「工人端 + 管理员端」业务场景的管理后台演示版。

## 技术架构

- 后端：Node.js 原生 HTTP 服务 + `node:sqlite` 数据库，零 npm 依赖
- 前端：原生 ES Module 单页应用 + Lucide 图标 + 自绘 SVG 图表
- 数据：启动时自动建表并灌入演示数据（告警、工单、考勤、监控点）

## 运行

需要 Node.js 24 及以上版本（内置 `node:sqlite`）。

```bash
cd smart-site-safety
npm start
```

打开 <http://localhost:5173>，演示账号：`admin` / `admin123`。

工人端移动界面：<http://localhost:5173/worker.html>，演示手机号：`13800138001`（王建国）等。

如需更换端口：

```powershell
$env:PORT=8080
npm start
```

## 功能模块

- 安全总览：核心指标、7 日隐患趋势、类型分布、区域安全指数、实时告警流
- 实时监控：多路 AI 视觉画面模拟、安全帽/脚手架隐患识别框
- AI预警中心：分级筛选、详情查看、一键转工单、忽略
- 隐患工单：新建工单、派单 / 整改 / 复核 / 销号闭环流转
- 人员考勤：班组台账、签到签退、安全帽佩戴、安全积分
- 数据统计：30 日趋势、区域风险、工单状态、闭环情况
- 系统设置：AI 识别阈值与预警策略

工人端（移动 H5）：

- 首页：人脸签到 / 签退、安全积分、通知公告
- 隐患上报：现场拍照、类型与描述提交，实时进入管理员预警中心
- 我的工单：开始整改 / 整改完成反馈，闭环流转
- 安全微课：必修课程与违章警示库
- 个人中心：个人信息、近 7 日考勤、积分明细
